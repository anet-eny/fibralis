# Blank starter

Minimal, production-ready baseline for a new Next.js + TypeScript + Tailwind v4 project.

## Scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
```

## Project structure

- `src/app/layout.tsx`: App shell + metadata
- `src/app/page.tsx`: Home page ("New Project")
- `src/app/globals.css`: Tailwind v4 entrypoint
